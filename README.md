# bank-loan-process-bpmn
Моделирование бизнес-процесса оформления потребительского кредита (AS-IS)
О проекте

Учебный проект по бизнес-анализу, посвящённый моделированию существующего процесса оформления потребительского кредита в отделении банка.

Цель: разработать BPMN 2.0-модель процесса от обращения клиента в банк до получения кредитных средств, включая альтернативные сценарии и проверки кредитоспособности.

Выполненная работа

Определены участники бизнес-процесса и их зоны ответственности.

Построена BPMN 2.0-диаграмма AS-IS.

Описаны основной и альтернативные сценарии процесса.

Смоделированы проверки документов, самозапрета и кредитоспособности.

Подготовлено текстовое описание процесса и бизнес-правил.
